# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be respectful, assume good faith, and keep discussion about the work. Harassment, personal attacks, and publishing other people's private information are not accepted.

Report conduct problems through a private maintainer contact method when one is available. If no private contact method is listed, use GitHub's built-in reporting or abuse tools and do not post sensitive details in a public issue. Maintainers may remove content and restrict participation that violates this code.

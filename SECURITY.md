# Security policy

This repository contains instructions for AI assistants, small Python examples, and a file backup helper. The helper is the only code intended for real use.

## Reporting a vulnerability

Please use GitHub's **private vulnerability reporting** (the "Report a vulnerability" button under the repository's Security tab). Do not open a public issue for a vulnerability, and do not include real credentials or private data in any report.

Relevant reports include, for example, a way for the backup helper to overwrite or expose files outside its intended destination, or skill wording that would lead an assistant to delete data, reveal secrets, or exceed its authorization.

## Supported versions

Until the first release, fixes go to the main branch. After that, only the latest release receives fixes.
